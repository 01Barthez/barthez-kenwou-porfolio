# 🌐 Internationalization (I18n)

The portfolio supports multiple languages to reach a global audience.

## Technologies
- `i18next` & `react-i18next`.
- `i18next-browser-languagedetector`.

## Implementation
1. **Detection**: Automatically detects browser language.
2. **Persistence**: Saves choice in cookies/localStorage.
3. **Architecture**: JSON-based translations located in `public/locales/` or `src/shared/lib/i18n`.

## Usage
Use the `useTranslation` hook from `react-i18next` for textual content.

```tsx
const { t } = useTranslation();
return <h1>{t('home.hero.title')}</h1>;
```
