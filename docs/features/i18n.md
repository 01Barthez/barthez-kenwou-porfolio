# Internationalization (i18n)

The portfolio supports English and French.

## Default

**English** is the default on first visit. French is applied only when the user uses the language toggle (persisted in `localStorage` via Zustand).

## Technologies

- `i18next` & `react-i18next`
- `useLanguageStore` (`src/shared/state/useLanguageStore.ts`) — source of truth + persistence
- `I18nProvider` — syncs `i18n.changeLanguage(language)`

Browser auto-detection is intentionally disabled so FR browsers still land on English until the user toggles.

## Usage

```tsx
const { t } = useTranslation();
return <h1>{t('home.hero.title')}</h1>;
```

Or read the store for bilingual content fields:

```tsx
const { language } = useLanguageStore();
const title = language === 'fr' ? post.titleFr : post.titleEn;
```
