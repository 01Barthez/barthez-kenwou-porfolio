## 🛠 Tech Stack Overview

- **Core**: React 18, TypeScript, Vite (Rolldown)
- **Styling**: Tailwind CSS 4, Framer Motion
- **Content**: Velite, Shiki, React Markdown
- **Testing**: Vitest, Cypress
- **Quality**: Lighthouse CI, Husky, Commitlint
